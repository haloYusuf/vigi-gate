Prompy 5 (Penjelasan endpoint di Front End)
Selanjutnya, disini aku jelaskan ke kamu terkait endpointku, disini ada 5 endpoint:
Base URL:http://localhost:8080/vigi/v1
Endpoint 1 : /dashboard/stream (GET)
Ini endpoint dengan tipe MediaType.TEXT_EVENT_STREAM_VALUE, dimana dia realtime untuk mengecek siapa saja yang CHECKED_IN di backend, dengan eventnya bernama 'dashboard-update', outputnya:
"totalActiveGuests": 0 dan ListactiveGuests yang isinya di tiap list adalah(visitId, nik, nama, photo, purpose, riskStatus, checkInTime)
Endpoint 2: /dashboard/today (GET)
Ini endpoint yang nanti konsepnya tombol Summary data Today, ketika ditekan, endpoint ini dipanggil dan akan loading untuk call AI merangkum semua data yang CHECKIN hari ini dan akan memberikan highlight, result jika berhasil : {"result":"", "totalGuest": 0}
Endpoint 3: /reg/{NIK} (GET)
Konsepnya, ketika ada yang mau checkin, kan pengguna memasukkan NIKnya dulu, lalu dicek pakai endpoint ini, dengan output:
{nama bisa null, photo bisa null, hasActiveVisit true/false, registered true/false}
Jika registerednya false, maka tampilan selanjutnya isi nama, photo (url), dan purpose.
tapi jika tegisterednya true, langsung input purpose (nama dan photonya otomatis terisi).
Endpoint 4: /reg/checkin (POST)
Perlu body berupa nik, nama, purpose, dan photo.
Berfungsi untuk checkin, resultnya adalah id, guest(isinya ada id, nik, nama, photo), purpose, checkInTime, checkOutTime, riskStatus (Antara RED, YELLOW, atau GREEN), dan visitStatus(Pasti Checked_In)
Endpoint 5: /reg/checkout/{id} (PUT)
Menggunakan id (bukan id guest), Outputnya sama seperti checkin kecuali di bagian visitStatus(Pasti Checked_Out)
Nah dari kelima endpoint itu, alurnya adalah, halaman awal menunjukkan list dari orang yang ada pada lokasi (Menggunakan endpoint 1) dan realtime (kalau ada yang berubah otomatis datanya ikut berubah), lalu ada tombol untuk menampilkan dialog, di dialog tersebut, pengguna memasukkan nik lalu menekan tombol next, ketika tombol next ditekan, maka akan menjalankan endpoint 3, lalu kalau hasil dari endpoint 3 itu adalah true untuk registerednya, maka akan muncul informasi nama dan foto yang tidak bisa diedit, dan ada textfield untuk tujuan (purpose), kalau false, maka akan muncul textfield untuk nama, foto, dan tujuan.
Dan ada juga tombol add yang nanti ketika ditekan akan hit endpoint 4. Lalu di list awal tadi ada tombol untuk checkout, yang ketika ditekan akan muncul peringatan, dan ketika diklick yes, akan otomatis hit endpoint 5. Dan ada juga tombol diluar list, yang diberi nama (Summary today), ketika di klick akan loading dan hit endpoint nomor 2, nanti resultnya akan muncul di section atas tombolnya. Akan ada penanganan error jika httpnya 400+ atau 500+.
